# Bugku CTF 瑞士军刀 writeup

## 题目类型:PWN(二进制漏洞利用)
## 题目描述:`ls`
## 目标地址:`nc 160.202.254.160(随机端口)
## 解题思路
1. ”瑞士军刀“特指网络工具netcat(`nc`),暗示我们需使用其来连接靶机
2. `ls`命令在Linux中用于列出当前目录文件，暗示我们需用`ls`查看目录，再用`cat`读取flag文件
## 解题过程
1. 在微软应用商店搜索并安装kali linux。且以管理员身份打开powershell,输入`nable-WindowsOptionalFeature -Online -FeatureName Microsoft-Windows-Subsystem-Linux`和`Enable-WindowsOptionalFeature -Online -FeatureName VirtualMachinePlatform`，使系统更新到最新版
2. 再次打开kail,初始化kail
3. 安装必备工具：因为商店下载的 Kali 是极简版，没有 sudo 和 nc。
   · 在 Windows PowerShell 输入` wsl -u root` 切换到 root 用户。
   · 在 root 权限下执行：`apt update `更新源。
   · 安装工具：`apt install sudo netcat-traditional -y`。
4. 启动场景后，在kail输入目标地址，再根据提示输入`ls`查看文件列表(出现flag文件)，后输入`cat flag`读取文件，出现flag
# 踩坑记录
1. WSL 报错 0x8007019e：初次打开 Kali 报错，原因是未启用 WSL 功能。必须用管理员身份执行启用命令，并重启电脑。
2.  命令未找到：极简版 Kali 没有 sudo，导致 sudo apt update 失败。需要 wsl -u root 切入 root 用户后再安装。
3.  密码无回显：Linux 里输入密码不显示字符，不是键盘坏了，是安全机制。
