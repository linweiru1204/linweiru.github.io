# bugku CTF-这不是md5 writeup

## 题目信息

1. 题目名称：这不是md5
2. 题目分类： Crypto
3. 题目描述：666c61677b616537333538376261353662616566357d

## 解题步骤

1. 观察字符串仅有数字0-9和字母a-f组成，字符串长度为42位，推断为十六进制编码
2. 每两个十六进制数字对应一个ASCII字符，通过在控制台进行JavaScript解码
```
var hex_str = "666c61677b616537333538376261353662616566657d";
var flag = "";
for (var i = 0; i < hex_str.length; i += 2) {
    flag += String.fromCharCode(parseInt(hex_str.substr(i, 2), 16));
}
console.log(flag);
```
## md5和十六进制区别

1. 本质：md5是一种哈希算法（数学运算）。它的作用是将任意长度的数据“打碎”成固定长度的指纹；十六进制（Hex）：是一种数制（编码方式）。它只是一种展示数据的方式（用0-9和a-f表示）
2. 特征：MD5：不可逆（单向）。你无法通过MD5值倒推回原始密码。且结果长度固定（永远是32位十六进制字符）；十六进制：完全可逆。可以把十六进制转回原始文本（ASCII）。且长度不固定
3. 区分技巧：一串字符，若为32位十六进制，则考虑为md5
