# BUGKU 变量1 writeup
## 题目类型：web
## 题目名称：变量1
## 解题步骤
1. 启动场景后，出现的代码为
````
flag In the variable ! <?php  
error_reporting(0); //关闭所有PHP错误报告（即使代码运行出错也不会在页面上报错，防止泄露服务器路径或输出干扰信息）
include "flag1.php"; //将"flag1.php"这个文件内容包含到当前脚本中
highlight_file(__file__); //将当前文件的源代码高亮显示在页面中(__file__代表当前脚本的绝对路径)
if(isset($_GET['args'])){ //检查是否通过GET请求，传递了名为args的参数($_GET是PHP接收URL参数的超全局变量)
    $args = $_GET['args']; //接收GET参数args的值，赋给变量$args
    if(!preg_match("/^\w+$/",$args)){//(正则：`/^\w+$/`,等价于[a-zA-Z0-9_],代表大小写字母，0-9数字，下划线)（^代表字符串开头，$代表字符串结尾，二者一起，要求整个传进来的args全都只能是\w里的字符，不能有其他）
                                     //(+表示至少要有一个字符)
        die("args error!");//如果$args不能匹配此正则，就报错
    }
    eval("var_dump($$args);");//(eval规则：把双引号里面的字符串，当成PHP代码运行）（`var_dump()`的作用：打印这个变量的内容，类型）（PHP双引号会自动解析里面的变量）（$$flag等价于${$flag},等价于$flag)
}
?>
```
2. 解题思路是让$$args等价于$flag,所以构造拼接GET参数xxx.php?args=GLOBALS(PHP中，$GLOBALS是包含了当前脚本所有全局变量的大数组)
3 .输入后，$args="GLOBALS",$$args=$GLOBALS,eval执行var_dump($GLOBALS)
